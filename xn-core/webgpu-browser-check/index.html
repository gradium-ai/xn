xn WebGPU checks

Run these on whatever device you are holding.

1. Capability check Does this device meet what the backend needs? No download — pure JavaScript. 2. Backend harness Runs the real xn WebGPU backend compiled to wasm: correctness across the op set, and a benchmark.

If WebGPU appears to be missing

It needs a secure context. Over plain http:// from a LAN address navigator.gpu is absent no matter how capable the device is. This server also speaks HTTPS with a self-signed certificate — use that URL and accept the warning (Advanced, then Proceed).
